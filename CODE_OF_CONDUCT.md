# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and don't
harass anyone. Harassment, personal attacks, and discriminatory language are
not tolerated in issues, pull requests, discussions, or any other project
space.

## Reporting

If someone's behavior is a problem, contact the maintainer privately through
GitHub (the repository owner). Reports are handled confidentially. The
maintainer may remove comments, close threads, or block participants who
violate this code.
